Goal: no new features. Sweep every existing page, tool, and integration; find what's broken, weak, or half-wired; fix in ranked order so real users can sign up, practice, and pay without friction.

## Phase 1 — Deep Audit (read-only sweep, ~1 pass)

I'll go through the app in these buckets and produce a written "issue log" per bucket (file:line, severity, fix idea). No code changes in this phase.

- `index.html` — favicon (`/favicon.png` present, no `.ico`), OG image `/og-image.jpg` existence check, splash screen dismissal, apple-touch icons for all sizes, manifest icon set (maskable + iOS splashes).
- Landing page (`LandingPage.tsx`) — hero LCP, CTA to signup, broken sections, image loading, mobile layout on 375/414/508 widths.

## Phase 2 — Fix Ranking

After the sweep, findings get sorted into 4 tiers. Fix top-down.

### Tier 1 — Blocker (users can't sign up, pay, or practice)
Anything that breaks: sign-in, Google auth, onboarding save, Paddle checkout, premium unlock after payment, core audio playback, protected route redirect loops.

### Tier 2 — Critical (feature visibly broken / data loss)
Buttons that do nothing, forms that don't save, streak resets, journal entries lost, coach chat fails, SOS panic protocol crashes, missing PWA icons, favicon regression.

### Tier 3 — Weak spots (works but poor UX / trust)
Missing empty states, ugly loading spinners, mobile layout breaks, unclear pricing copy, missing legal links, unverified Paddle live keys, weak error toasts, missing analytics events for the 6 north-star funnels (signup → onboarding → first session → day-3 → premium view → purchase).

### Tier 4 — Polish (nice, not urgent)
OG image quality, sitemap freshness, minor copy fixes, un-instrumented events, video bucket gaps.

## Phase 3 — Fix Passes (one PR-sized batch per tier)

Each pass: implement fixes, verify with build + Playwright click-through of the affected routes, re-read console/network. No new features get added — if I discover a missing feature the user expected, it goes in a "deferred" list, not this plan.

```text
Pass 1  →  Tier 1 blockers   (auth, payments, core playback)
Pass 2  →  Tier 2 critical   (broken buttons, data loss, PWA)
Pass 3  →  Tier 3 weak spots (UX, mobile, trust, analytics wiring)
Pass 4  →  Tier 4 polish     (OG, sitemap, copy)
```

After each pass: I report back with "fixed X, verified Y, remaining Z" so you can decide whether to continue or ship.
